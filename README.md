# BIST Teknik Analiz

Python 3.10+ gerektirir.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Tarayıcıda açılan ekrana ALARK gibi BIST kodu yazıp **Analiz et** düğmesine basın.

Veri kaynağı Yahoo Finance (yfinance); BIST verileri gecikmeli, eksik veya hatalı olabilir. Günlük analiz yapılır, otomatik emir göndermez. Göstergeler geçmiş fiyatlardan hesaplanır, kazanç garantisi vermez. Güncel veri ve şirket kodunu KAP/BIST ile teyit edin.
